# Become - Қайта бағыттау беті

> **Language / Язык / Тіл:** [English](README.md) | [Русский](README_ru.md) | [Қазақша](README_kk.md)

Пайдаланушыларды форма бетіне қайта бағыттауға арналған React қосымшасы.

## Орнату

```bash
npm install
```

## Әзірлеу

```bash
npm run dev
```

## Продакшен үшін құрастыру

```bash
npm run build
```

Құрастырылған файлдар `dist/` қалтасында болады.

## Типтерді тексеру

```bash
npm run typecheck
```

## Орналастыру

Құрастырудан кейін `dist/` қалтасының мазмұнын веб-серверге көшіріңіз немесе GitHub Pages пайдаланыңыз.

### GitHub Pages

1. Жобаны құрастырыңыз: `npm run build`
2. `dist/` мазмұнын репозиторий түбіріне көшіріңіз немесе автоматты орналастыру үшін GitHub Actions баптаңыз

## Технологиялар

- React 18
- TypeScript
- Vite
- CSS3

## Ерекшеліктер

- 3 секундтан кейін автоматты қайта бағыттау
- Кері санақ таймері
- Қолмен өту үшін қосалқы түйме
- Адаптивті дизайн
- Циклдік қайта бағыттаулар жоқ
