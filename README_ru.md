# Become - Страница перенаправления

> **Language / Язык / Тіл:** [English](README.md) | [Русский](README_ru.md) | [Қазақша](README_kk.md)

React приложение для перенаправления пользователей на форму.

## Установка

```bash
npm install
```

## Разработка

```bash
npm run dev
```

## Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `dist/`.

## Проверка типов

```bash
npm run typecheck
```

## Деплой

После сборки скопируйте содержимое папки `dist/` на ваш веб-сервер или используйте GitHub Pages.

### GitHub Pages

1. Соберите проект: `npm run build`
2. Скопируйте содержимое `dist/` в корень репозитория или настройте GitHub Actions для автоматического деплоя

## Технологии

- React 18
- TypeScript
- Vite
- CSS3

## Особенности

- Автоматический редирект через 3 секунды
- Визуальный таймер обратного отсчёта
- Резервная кнопка для ручного перехода
- Адаптивный дизайн
- Отсутствие циклических редиректов
